R:

Dados - Um fato que pode ser armazenado e tem significado implicito(dedutivel) - ex: nome (subtendese tratar da descrição de algo ou alguem)

Banco de dados  - local pra armazenar e gerenciar um coleção de dados

SGBD - Sistema de gerenciamento de banco de dados (software que organize de maneira mais clara os sistemas relacionados ao banco de dados )

sistema de banco de dados - todo um sistema que faz o ambiente de banco de dados funcionar - procedimentos, pessoas, daddos , hardware

catálogo de banco de dados? 

independência entre dados e programas - cada aplicação pode acessar os dados que bem entender, independete da aplicação(Incluir o campo "telefone" na 
tabela de clientes. O sistema de cadastro continua funcionando sem alterações no código fonte básico).

visão do usuário  - é uma tabela virtual baseada no resultado de uma instrução SQL

DBA  - Administrador de banco de dados - Trata-se do profissional de tecnologia responsável por gerenciar, configurar, otimizar, monitorar, fazer backups e garantir a segurança e a alta disponibilidade dos dados de uma organização.

usuário final  - usuário sem entendimento técnico que apenas vai acessar os dados via aplicação de maneira indireta
