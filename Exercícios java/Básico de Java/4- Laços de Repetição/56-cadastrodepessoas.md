Crie um programa que permita cadastrar pessoas.

Para cada pessoa, leia:

Nome
Idade

Ao final de cada cadastro, pergunte:

Deseja cadastrar outra pessoa? (S/N)

Enquanto o usuário responder S, o programa continua.

Quando responder N, exiba:

Quantidade de pessoas cadastradas.
Média das idades.
Nome da pessoa mais velha.
Idade da pessoa mais velha.
